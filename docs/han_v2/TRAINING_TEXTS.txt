[offset 3311]
This is the command range.  Here you will learn how to use the command interface to issue orders to the other soldiers of your platoon.  Press the START button at any time to exit training.

[offset 3506]
This is the demolitions range.  Here you'll learn how to place a claymore antipersonnel mine and detonate it.  This same technique is used for placing demolitions charges and battlefield sensors.  Press the START button at any time to exit training.

[offset 4168]
This is the grenade range.  Here you'll learn how to throw hand grenades and fire a grenade launcher. Press the START button at any time to exit training.

[offset 5082]
This is the machine gun range.  Here you'll learn how to fire a fixed machine gun.  Press the Start Button at any time to exit training.

[offset 5224]
The obstacle course will teach you how to move through the world.  Use the left analog stick to move forward and back and side-to-side.  Use the right analog stick to turn, and look up and down.  Press the left analog stick hard to run.  Press the START button at any time to exit training.

[offset 5520]
The route to the next training range is through this darkened hallway.  Switch on your night vision goggles with the Night Vision Button.  Night vision is essential in low-light situations, but you'll see better in full illumination with it switched off.  When you leave the darkened area, press the Night Vision Button again to switch it off.

[offset 5869]
When you're standing still you can peek around obstacles.  Press the Left and Right Peek Buttons and practice using the barrier.  Remember, the smaller the target you present to the enemy, the harder for you to get hit.

[offset 6646]
This is the rocket range.  Here you'll learn how to fire antitank rockets. Press the START button at any time to exit training.

[offset 7118]
This is the small arms range.  Here you'll learn how to fire a rifle and a pistol, how to switch weapons, reload and use a scope. Press the START button at any time to exit training.

[offset 7306]
The sniper rifle is equipped with a scope for long-range shots.  Use the Zoom In/Out buttons for continuous zoom control.  Practice hitting the long-range targets.

[offset 7820]
The other soldiers in your platoon are in the courtyard below.  Press the Command Map Button to call up the command interface.
