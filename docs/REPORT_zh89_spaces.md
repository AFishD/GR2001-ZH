## 1. 上一轮（r27）漏计的根因 —— 扫描脚本 bug 复盘（留档）

上一轮清单只报 **69 处**可见缺陷，实为 **1730 处**。差异**不是**判定口径不同，而是 `work/_dis/r27_scan2.py`
的「token → 渲染行号」映射在遇到**硬断 token（SW > 270）**后失效：

```python
for li, line in enumerate(lines):                 # lines = 模型输出的渲染行
    for t in [x for x in line.split(' ') if x]:
        if ci < len(toks_) and t == toks_[ci]:    # ← 硬断把行切成"碎片", 碎片 ≠ 完整 token
            tok_line[ci] = li; ci += 1            #    ⇒ 匹配失败, ci 停摆
```

硬断行被切成的碎片永远匹配不上完整 token，`ci` 从此不再前进 ⇒ **该条文本此后所有 token 都没有行号**，
于是「两侧 token 是否同一行」的判据全部落空、可见空格被静默丢弃。这解释了漏计集中在长文本：

| 文本 | r27 报告 | 本报告重扫（可见空格 / 最终删除） |
|---|---|---|
| 武器 32 条（无硬断） | 44 | **44**（可见数完全一致，证明口径相同）/ 删 89 |
| 奖章 `国会最高勋章` #43 | 1 | 2 候选 / 删 2 |
| 背景 `战争序幕 1` #65 | 6 | 33 候选 / 删 29 |
| 访谈 `开发访谈 2` #68 | 5 | 100 候选 / 删 94 |
| 人物档案 `斯通` #50 | 0（整族未列） | 26 候选 / 删 19 |
| 合计 | 69 | **1730** |

⇒ 本报告改用「引擎口径解码 + `{br}`/`{p}` 分段 + 逐字符行号」三件套重扫（`work/_dis/r28_lib.py`），
并把每个判定都做成可复核的**字节级白名单**。

## 2. 判定链（全部可复核）

1. **解码**：DBCS lead 只认 `0xA1..0xAD`（ELF 四处 `sltiu reg, lead, 0xAE`），`0xAF..0xFE` 是单字节码
   （`的 = 0xAF`）⇒ 避免"贪心 pair-first"把 `的方` 解成 `弗开` 的假象。
2. **分段**：`RSHTML::CreateStrings` 先按 `{br}`/`{p}` 把文本切段，**每段各自折行**（预算重置）。
3. **折行**：`RSTextComponent::DoWordWrap`，wrapW = 270、汉字 16、ASCII 8。
   * 旧口径（r27）：每 token 扣 `SW + 空格(4) + tracking(1) + 尾随空格(4)`；
   * **标定后口径（本轮）**：每 token 扣 `SW + tracking(1)`，每个字面空格扣 `SP`，断行时新行预算 `= wrapW − SW(token)`。
4. **可见性**：0x20 画在其**前一 token 的行尾** ⇒ 只有「后一 token 首行 == 前一 token 末行」时才有墨迹空隙。
5. **溯源**：`work/_dis/_xml82.txt`（zh84 reflow **之前**的台账）去空格后**逐字符对齐 58/58 条**
   ⇒ 每个可见空格判为`原文固有`(849) 或`reflow 插入`(881)；只删后者。
6. **逐处复算 + 贪心**：删该处（并等量补尾）后，**每个存活字符的 (段号,行号)** 与原文一致才接受；
   会重排的**保留不动**。

## 4. 写入方式与白名单

补丁：`tools/iso_build/patch_zh_sf_spaces_all.py`（由 `work/_dis/r28_mkpatch.py` 生成）

* **白名单逐处**：(文档序, XML 绝对偏移, 前置 6 字节 hex, 后置 6 字节 hex) —— 792 条全部硬编码；
  运行时逐处断言「落在该 `<text>` 体内 / 该字节就是 0x20 / 前后字节全等」，并断言总数 == N_DEL。
* **等长覆写**：每条 `<text>` 删 N 个 0x20，在**最后含 token 段**的末尾补 N 个 0x20（末行行尾 ⇒ 无墨迹）
  ⇒ XML 总长 116486 B 不变 ⇒ 8 子流解压尺寸不变 ⇒ 子流边界不变 ⇒ 其余字节逐字节不变。
* **只重压受影响的子流**：子流 0–4 重压（`3569→3569 / 5707→5693 / 10467→10410 / 12341→12306 / 9145→9032`），
  子流 5–7 原样沿用；帧 `41795 → 41576 B`，槽 49700（余 8124）。
