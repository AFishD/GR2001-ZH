# 受限字表文案改写报告（round64 · `text_reduce`）

> 目标：**不动字库、不扩容量**，把用户新写的文案改写到"只用现役字库已有的字"，
> 手法是**同义替换／改写**，并**优先处理用量少的超范围字**。
> 分支 `main`；未 commit、未切分支；未改任何 ISO；未改字库 JSON 与 `tools/text_csv/*`。

---

## 1. 用户需求

原话：

> 开一个 subagent 在现在版本的字库范围内进行缩减，将用量少的字尽量在范围内替换为同义词。

即：**字库容量锁死**（现役 1285 字），把超出字库的新译文用**同义字／换说法**压回范围内，
并且**先解决只出现 1~3 次的低频字**，再处理高频字。

## 3. 手法与策略

### 3.1 关键发现：盘上旧译文是"字库内活字典"

`text_zh`（盘上现值 = 旧译文）**每个字都在字库内**（否则盘上早就显示空白），
而它翻译的是**同一段英文原文**。因此它天然给出了"这个意思在现役字库里能怎么说"：

| 新译文（超范围） | 盘上旧译（字库内） | 采用 |
|---|---|---|
| 6英尺（183厘米） | `6'0" (183 cm)` | 改用 ASCII 单位 |
| 瞳色：棕色 | 眼：蓝色 / 发色：深色 | 眼色 / 深色 |
| 性别：男 | 性别：M | 性别：M |
| 个人履历 | 过往 | 个人档案 |
| 她 | 他（旧译通篇用"他"） | 他 |
| 父亲（托马斯） | `Thomas 从外事工作退休` | 家长／直接用名字 |
| 卒于 1990 年 | 1990 年去世 | 去世 |
| 荣获 / 授予 | 发给 / 获得 | 发给 / 获得 |
| 狙击手 | 狙击手 | 保留 |

### 3.2 六类手法（按使用量排序）

1. **同义字替换**（1511/1587 处改动区块）：`她→他`、`授予→发给`、`卓越→突出`、
   `杰出→优异`、`瞳色→眼色`、`棕色→深色`、`均→都`、`卒于→去世`、`厘/尺/寸→cm / ' / "`。
2. **换说法**：`欣慰→开心`、`嘲讽→说刻薄话`、`荒凉→…`、
   `逞凶→…`；`虔诚` 类抽象词改成具体说法。
3. **拆分/合并短句**：`俯瞰敌军的高点 → 从高处看敌军的位置`；
   `目瞪口呆 → 极为吃惊`。
4. **调整语序**：`他仅有的乐趣 → 他唯一的快乐`；`被视为表彰英勇作战的最高荣誉 →
   被视为对果敢作战的最高奖励`。
5. **中西文人名/地名改用字库内音译字**（保中文观感）；
   实在凑不出可用音译字的才退回**拉丁原文**（ASCII 可用，且**盘上旧译本来就这么写**：
   `Thomas` / `London` / `Oxford`）。
6. **中文数字 → ASCII 数字**：字库缺 `五/七/八` ⇒ `第五→第5`、`十五→15`。

### 3.3 优先处理低频字（用户明确要求）

工作顺序刻意做成"**先清长尾**"：
先把 693 种字按出现次数排序，从 1~3 次的开始逐个查上下文、写词级替换规则，
高频字（`她/父/历/业/狂`…）反而最后收敛。

| 出现次数 | 种类数 |
|---|---|
| 1 次 | **342 种** |
| 2 次 | **138 种** |
| 3 次 | **71 种** |
| **1~3 次合计** | **551 种 / 831 次**（占全部出现次数的 45.5%） |
| ≥10 次 | 24 种 |

最终 693 种字**全部清零**——即用户点名要优先处理的 551 种低频字，
连同剩下的 142 种高频字，一个不剩。

### 3.4 工具链（可复现）

| 脚本 | 作用 |
|---|---|
| `reduce_lib.py` | 可用字集 / 缺字自查 / 目标导出（与预检同口径） |
| `reduce_check.py` | **改写稿快速自查**（超范围字 + `{WRAP}` 写法与位置），exit 0 = 干净 |
| `reduce_ctx.py` / `reduce_todo.py` | 打印每个超范围字的**实际上下文**（含原文），供决策 |
| `reduce_rules.py` | **替换规则表**（1486 条：NAME 63 + 通用 1402 + 条目专属 21） |
| `reduce_rulecheck.py` | **规则表机器校验**：改后片段链式过一遍后续规则后仍含超范围字 ⇒ 报错 |
| `reduce_apply.py` | 套规则生成改写稿 |
| `reduce_review.py` | 逐处列出"替换前→替换后"上下文（含原文），用于人工复核 |
| `reduce_dups.py` | 查"规则叠字"（`被选拔入→被选入入` 这类） |
| `reduce_write.py` | 写回 CSV；`--verify` 做**字节级回环自检** |
| `reduce_map.py` | 生成改写对照表 `reduce_map.csv` |

> 规则表有 **1486 条**，靠机器校验而不是靠眼睛：
> ① `reduce_rulecheck.py` 拦住"改后仍有超范围字"的规则；
> ② `reduce_check.py` 拦住改写稿里残留的超范围字；
> ③ `reduce_dups.py` 拦住规则造成的叠字；
> ④ `reduce_review.py --deletions` 逐处复核"删字兜底"有没有把词切坏
>   （这一项抓出并修掉了 ~40 处 `英[雄]行为`、`波[兰]语`、`[灌]木` 这类切词）。
