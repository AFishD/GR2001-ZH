1. **重新 dump 基线表**：`dump_sf_titles_csv.py --iso GR_ZH111.iso` → 145 行（含 `text_en` 英文原名、

   （`GR_ZH111_text_long.csv` 的 `text_zh`）都压掉空白后逐词搜索，找出**同名概念**的用词
   （人名 / 勋章名 / 装备名 / 资料片名 / 文章标题）。条目 ↔ 正文的映射按内容逐条核对过
   （T0010..T0040 ↔ A0055..A0085；T0043..T0049 ↔ A0116..A0122；T0050..T0062 ↔ A0124..A0136；
   T0063..T0069 ↔ A0138..A0145）。
4. **结构键复核**：独立重扫盘上 **10 份** SFXML 副本的 145 个 `name` 属性（`r68/studio_evidence.txt`）。
5. **字表**：以 `r64/available_charset.txt`（**扩容前**导出的现役 1285 字）为基线白名单，
   外加真字形检查（`GlyphCache`）与注入器 `--check-only`。
6. **长度**：用项目自己的折行模型 `tcslib.strlen`（CJK 16px / ASCII 8px / 每字 1px 字距）算宽度增量。
