# ★ 与之前几版的**关键修正** (逐帧比对得出, 见 ab/m_filesel.png vs ab/m_filesel_before.png):
#   1. 「选择文件」屏的**初始高亮就是第 1 个档案 (TEQSUNSET, 顶部)** —— 千万不要按 up!
#      之前几版照抄 nav_sf6 的 "up×3", 实测会把高亮从档 1 **上绕到最底的「新建」**,
#      于是 f3250 的 cross 变成"新建档案" ⇒ 进「输入名字」键盘屏, 永远到不了主菜单。
#      (成功轮与失败轮在同一帧 f2900 的差别就是: 成功轮档 1 是金色高亮条, 失败轮金色在「新建」上。)
#   2. 因此本版**只按一次 cross 载入档 1**, 之后主菜单约 f4000 起就绪。
#   3. 菜单按键全部用 `tap` + 紧跟 `release`(fr+2) 的 **2~3 帧短按**
#      (GRResearch.cpp: `tap` 默认按住 12 帧 ⇒ 本作菜单按住 ~7 帧即连发, 单 tap 会移 2~3 项)。
#   4. 时序放宽: 主菜单下移从 f4800 开始 (留足菜单出现/输入解锁的时间)。
